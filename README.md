# Смены — календарь механика

| Файл | Что это |
|---|---|
| `index.html` | Календарь (сайт и мини-приложение в Telegram) |
| `calc.js` | **Общий расчёт** денег и баллов — им пользуются и календарь, и бот |
| `calc_test.js` | Проверки расчёта. Без них ничего не выкладывается |
| `worker.js`, `wrangler.toml` | Бот @smeny_mechanic_bot (Cloudflare) |
| `build.js` | Сборка сайта перед выкладкой |
| `.github/workflows/deploy.yml` | Автовыкладка |

**Как обновлять:** загрузить изменённые файлы сюда, в smeny-. Дальше всё само:
проверки → сайт smeny- → сайт smeny-team → бот. Ход выкладки — во вкладке **Actions**.
Если проверки не прошли, ничего не меняется, а GitHub присылает письмо.

`index.html` и `calc.js` всегда загружайте вместе.
